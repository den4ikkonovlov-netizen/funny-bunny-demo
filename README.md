# Фанни Банни

Статический сайт студии детских праздников в Северодвинске. Без сборки и сторонних JavaScript-зависимостей. Готовые файлы находятся в `dist/`.

## Просмотр

Запустите `npm run dev` из этой папки или из родительской папки «Фанни Банни». Откройте http://127.0.0.1:4189. Устанавливать зависимости не нужно. Чтобы остановить сервер, нажмите Ctrl+C в окне терминала, где он запущен.

## Дизайн

Изучена полка https://polka-refov.vercel.app/ и примеры: Wilde Weide — смелая типографика и праздничный характер, Kibooq — дружелюбные формы и цвет, China Firework — выразительная композиция первого экрана. Референс https://firework.red-stone.net/ использован для понимания предпочтений заказчика. Итоговая композиция и рисунок зайца созданы для этого проекта.

## Данные и безопасность

Сайт не содержит базы, панели администратора, платежей, форм передачи персональных данных, аналитических трекеров или секретов. Все шрифты и фотографии локальные. Выбор пакета открывает карточку с фотографиями и описанием; бронирование происходит непосредственно в сообществе VK, после согласования с администратором. Никакие сообщения автоматически не отправляются.

Ограничивающая CSP задана в HTML, серверные защитные заголовки описаны в `dist/_headers` для совместимого хостинга. Их применение зависит от платформы; HTML CSP действует независимо. Это не гарантия абсолютной безопасности инфраструктуры хостинга. Перед публичным запуском от имени студии владелец должен подтвердить актуальность цен, контактных данных и разрешения на использование фотографий. Это демонстрационная версия для просмотра заказчиком.

## Проверка

`node verify.mjs` проверяет локальные ресурсы, якоря и базовые ограничения. В браузере проверены компьютерная и мобильная версии, меню, выбор пакета, фото с перелистыванием, FAQ. Установку `prefers-reduced-motion` учитывают стили и анимации.
